# Privacy Policy — GitHub Drive Automation

Last updated: 19 October 2026

## Purpose
This application is used privately to connect the account owner's GitHub Actions workflows to their Google Drive.

## Data Access
The application requests Google Drive permissions authorised by the account owner. It may read, create and update files as required by the configured workflows.

## Data Storage and Sharing
OAuth credentials are stored in private GitHub Actions secrets. File contents are processed for the account owner's workflows and are not sold or shared with advertisers. Files may be transferred to GitHub Actions for processing.

## Revoking Access
The account owner can revoke access through their Google Account's third-party connections settings.

## Contact
For privacy enquiries, contact the application owner using the developer contact information supplied through Google's OAuth configuration.
